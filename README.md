# راصد – متابعة حضور المعلمين في الحصص الافتراضية

**راصد المبسّط**: صفحة واحدة لرصد حضور المعلمين في حصص Teams، مع تذكير واتساب وتقارير اليوم والأسبوع والشهر.
**راصد الآلي**: إضافة Chrome/Edge تدخل الحصص تلقائيًا في مواعيدها، وتتحقق من وجود المعلم، وتلتقط لقطة شاشة مختومة بالوقت.

- الصفحة على الإنترنت: https://makh1551.github.io/rased-lite/
- تنزيل الإضافة (آخر إصدار): https://makh1551.github.io/rased-lite/rased-auto.zip
- قالب الجدول: https://makh1551.github.io/rased-lite/rased-template.csv
- سياسة الخصوصية: https://makh1551.github.io/rased-lite/privacy.html

## تثبيت الإضافة
1. نزّل `rased-auto.zip` وفك ضغطه في مجلد ثابت.
2. افتح `edge://extensions` أو `chrome://extensions` وفعّل «وضع المطوّر».
3. «تحميل إضافة غير مضغوطة» ← اختر المجلد.
4. سجّل الدخول إلى Teams في المتصفح نفسه، ثم من «الإعداد والجدول» ارفع الجدول وشغّل «اختبار الإعداد».

## التحديث للمستخدمين
تفحص الإضافة كل 6 ساعات ملف `version.json`. عند صدور نسخة أحدث يظهر إشعار وشريط «تحديث جديد» داخل راصد، فيه زر التنزيل. يفك المستخدم الضغط فوق المجلد نفسه ويضغط ↻. بياناته لا تتأثر.

## نشر تحديث (للمطوّر)
1. عدّل الملفات في `extension/` و`docs/`.
2. ارفع رقم `version` في `extension/manifest.json` (مثل 1.3.0 ← 1.3.1).
3. اكتب ملخص التحديث في السطر الأول من `release-notes.txt`.
4. ادفع إلى `main`. ينشئ GitHub Actions الإصدار، ويحدّث الموقع و`version.json`، فيصل التنبيه لكل الأجهزة.

> ملاحظة: `docs/index.html` نسخة من صفحة راصد المبسّط، و`extension/app.js` و`app.html` هما الصفحة نفسها مقسّمة لتعمل داخل الإضافة.

## الخصوصية
كل البيانات على جهاز المستخدم فقط. لا خادم ولا تتبع.
